# 元宝派 · 话题生成 Demo

一个基于群聊消息流的话题自动识别与沉淀 Demo 原型，演示 AI 从真实群聊中识别「值得沉淀的话题」的判定过程。

## 🎯 在线预览

**[→ 点击打开 Demo](https://coolchaoying-commits.github.io/pai-topic-demo/)**

（无需下载，浏览器直接打开；建议用 Chrome / Edge / Safari）

## 📖 Demo 说明

### 5 类话题 × 4 类动作

- **话题类型**：实用指南型 / 议题判断型 / 事件共振型 / 真实体验型 / 群体共创型
- **处理动作**：新建 / 丰富（补充已有话题）/ 衍生（基于已有话题派生新话题）/ 放弃（克制不沉淀）

### 10 个 Demo Case 全景

| # | Case | 类型 | 动作 |
|---|---|---|---|
| D1 | PS5 选购讨论 | 实用指南 | 丰富 |
| D2 | PS5 必玩游戏 | 实用指南 | 新建+衍生 |
| D3 | 腾讯会议 AI 纪要吐槽 | 真实体验 | 丰富 |
| D4 | 微信状态三派激辩 | 议题判断 | 新建 |
| D5 | C 罗 41 岁补时绝杀 | 事件共振 | 新建 |
| D6 | 干饭突击队周年红黑榜 | 群体共创 | 新建 |
| D7 | 打工人 24 小时心路 | 真实体验 | 新建 |
| D8 | 没心气的结构性归因 | 议题判断 | 新建 |
| D9 | 团建安排 | 反例 | 放弃 |
| D10 | 水群闲聊 | 反例 | 留池 |

## 🕹️ 交互

- 顶部选择 case → 点「▶ 开始播放」
- 速度切换：1x / 2x / 4x
- 左侧：群聊消息流（按时序动画播放）
- 右侧：话题自动沉淀到「派内话题」栏
- 底部：时间轴带 marker（新建/丰富/衍生/放弃）

## ⚙️ 本地运行（可选）

```bash
# 需要本地 HTTP 服务器（不能直接双击 file://）
cd pai-topic-demo
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
