## 📖 这个 Demo 演示了什么

派内话题 ≠ 群聊摘要。AI 需要做两层判断：

1. **要不要沉淀**：群里这段对话是事务安排（不沉淀）、单人吐槽（不沉淀）、还是有价值的讨论（沉淀）
2. **怎么沉淀**：是新建一个话题、丰富已有话题、从老话题派生出新话题，还是先观察留池

### 五类话题

| 类型 | 特征 | Demo case |
|---|---|---|
| **实用指南型** | 决策框架 + 具体方案 + 可执行清单 | D1 PS5 选购 / D2 PS5 必玩游戏 |
| **议题判断型** | 多派观点 + 争议 + 沉淀价值 | D4 微信状态三派 / D8 没心气归因 |
| **事件共振型** | 外部事件触发 + 群体情绪反转 | D5 C 罗补时绝杀 |
| **真实体验型** | 一手经历 + 可复用洞察 | D3 腾讯会议 AI 纪要 / D7 24h 心路 |
| **群体共创型** | 多人协作 + 规则共建 + 产出物 | D6 周年红黑榜 |

### 四种动作

| 动作 | 含义 | Demo case |
|---|---|---|
| ✨ **新建** | 全新主题成立 | D4 / D5 / D6 / D7 / D8 |
| 🔄 **丰富** | 命中已有话题，补充新维度 | D1 / D3 |
| 🌱 **衍生** | 从主话题派生独立子话题 | D2（含父话题 + 衍生） |
| ⏸ **放弃 / 留池** | agent 主动克制，不沉淀 | D9（放弃事务安排）/ D10（留池观察） |
